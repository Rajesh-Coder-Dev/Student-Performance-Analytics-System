About the Platform Architecture

Institutional technology stack and software engineering design.

The Student Performance & Analytics System is an end-to-end academic software solution designed to centralize student records, evaluate marks, determine automated grade point averages (CGPA), rank students academically, and visualize departmental statistics. Built following the Model-View-Template (MVT) pattern, it guarantees data integrity, responsive visualization, and secure session management.

🐍 Python 3.13 ⚡ Django 6.1 🗄️ MySQL Database 📊 Chart.js 4 📄 ReportLab PDF Engine 🛡️ CSRF & Role Authentication
